## 📌 Project Title 
本项目基于 **Python 面向对象 + 模块化工程思想** 开发，是一款通用几何图形面积计算工具。  
项目彻底解耦业务逻辑，将界面、图形类、计算、换算、输出完全拆分，**一人一模块独立开发**，高度模拟企业团队开发流程。

### 支持图形
- 正方形 · Square
- 长方形 · Rectangle
- 三角形 · Triangle
- 圆形 · Circle

### 核心能力
- 双单位自适应：`cm / inch` 自动换算（1inch = 2.54cm）
- 全局异常拦截，杜绝闪退
- 计算高精度不丢精度，输出统一 3 位小数

## 🚀 Getting Started 
### 🔧 运行环境
> 无任何第三方依赖，**纯 Python 内置库运行**

- Python 3.8 +
- VS Code / PyCharm
- 全平台 Windows / Mac / Linux 兼容

### 📂 项目结构
- 项目主文件：main.py  
  负责程序图形界面、程序入口、全局模块调度与异常捕获
- 图形类模块：shapes.py  
  负责面向对象架构、基类与子类继承、图形工厂方法
- 计算核心模块：area_calculator.py  
  负责四种图形的高精度面积公式运算
- 单位换算模块：unit_converter.py  
  负责用户输入校验、英寸与厘米标准化换算
- 结果格式化模块：result_formatter.py  
  负责计算结果美化、小数统一、规范输出
- 项目文档：README.md  
  负责项目功能、结构、开发规范、使用方法说明

## 📘 Usage
### 🎯 操作流程
1. **选择图形类型**（下拉框切换四种图形）
2. **选择计算单位**（厘米 / 英寸）
3. **输入合法尺寸参数**
4. 点击 **计算按钮**
5. 查看完整格式化结果

### 📏 输出统一规范
- 所有长度 → **厘米、保留3位小数**
- 所有面积 → **平方厘米、保留3位小数**
- 输出内容：图形类型 + 原始尺寸 + 最终面积
