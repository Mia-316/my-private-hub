## Getting Started
本项目为原生Python本地控制台程序，**无需额外安装第三方库**，下载完整源码即可直接运行。程序将交互界面、图形实体、面积计算、单位转换、结果输出进行模块化解耦，各模块职责独立，降低代码耦合度。

### Prerequisites 依赖环境
- Python版本：**Python 3.8 及以上，推荐3.10‑3.12**
- 操作系统：Windows10/11、macOS、Linux均可
- 运行工具：终端 / PowerShell，用于执行Python脚本
> 仅使用Python标准库，不需要pip安装任何第三方包。

### Installing 安装流程
1. 将项目全部源码文件下载保存到本地同一个文件夹，**不要修改文件名、不要遗漏文件**。
2. 打开终端，切换工作目录到项目根目录。
```bash
cd 你的项目文件夹路径
```
3. 核对本地文件结构，保证文件齐全：
```tree
通用面积计算器/
├── main.py                 # 程序入口，用户交互界面
├── shapes.py               # 图形类、继承关系、工厂函数
├── area_calculator.py      # 面积计算核心模块
├── unit_converter.py       # 输入校验、英寸‑厘米单位换算
├── result_formatter.py     # 结果文本格式化输出
└── tests/                  # 各模块独立自测脚本
```
> 数据统一约定：传入图形类的尺寸参数必须预先换算为厘米；圆形接收参数为直径而非半径。
4. 启动运行程序：
```bash
python main.py
```

## Running the tests
项目测试分为业务功能测试、单位换算测试、异常输入测试、模块单元测试，全部用例通过代表项目功能完整可用。完整业务测试流程：选择图形 → 设置单位 → 输入尺寸 → 计算 → 查看保留 3 位小数输出。

### 功能测试
| 图形 | 输入参数（厘米） | 预期输出面积 |
|---|---|---|
| 正方形 | 边长 = 2 | `4.000 平方厘米` |
| 长方形 | 长3，宽4 | `12.000 平方厘米` |
| 三角形 | 底6，高4 | `12.000 平方厘米` |
| 圆形 | 直径 = 2 | `≈3.142 平方厘米` |

### 单位换算测试
换算标准：`1 英寸 = 2.54 厘米`
1. 正方形输入边长 `2 inch`，内部换算为 `5.080 cm`
2. 预期输出面积：`25.806 平方厘米`
3. 输出结果需要同时展示原始输入单位与换算后的厘米数值。

### 异常输入测试
下面各类输入都应当捕获，抛出`ValueError`并给出中文友好提示，程序不会直接崩溃退出：
- 空字符串输入
- 中文、字母、特殊符号等非数字内容
- 数值等于0
- 负数尺寸
> `main.py`统一捕获异常，展示错误信息，允许用户重新输入参数。

### 模块单元测试
`tests/`目录存放各模块自测脚本：
- `test_shapes.py`：测试图形工厂函数，验证图形对象实例创建
- `test_area_calc.py`：校验面积计算公式正确性；计算模块禁止使用round()，小数格式化交由输出模块完成
- `test_unit_convert.py`：单位换算、非法参数异常抛出测试
- `test_formatter.py`：输出文本格式、小数位数控制验证

运行单元测试示例：
```bash
python tests/test_area_calc.py
```

完整业务测试流程：选择图形 → 设置单位 → 输入尺寸 → 计算 → 查看保留3位小数输出。

## Usage
项目提供两种使用模式：①直接运行主程序进行交互式计算（普通使用者）；②代码导入模块调用API，适合二次开发复用计算能力。

### 程序交互使用
1. 终端执行 `python main.py` 启动程序；
2. 根据控制台提示，选择目标几何图形：正方形 / 长方形 / 三角形 / 圆形；
![通用面积计算器功能说明](通用面积计算器功能说明.png "通用面积计算器功能说明")
3. 选择输入单位：`cm`(厘米)、`inch`(英寸)；
4. 根据图形提示填写对应尺寸；
> ⚠️圆形输入参数为**直径**，不是半径；
5. 程序自动完成输入校验、单位换算、面积计算、文本格式化；
6. 控制台打印图形类型、原始输入、换算后尺寸、最终面积；
7. 支持循环多次计算，也可以选择退出程序。

### 模块API简要说明
> 开发调用注意：传递给图形对象的尺寸，**必须预先换算为厘米单位**。

| 文件 | 核心函数 | 功能说明 |
|---|---|---|
| shapes.py | `create_shape(shape_type, params)` | 工厂函数，生成图形实例；定义抽象基类Shape及其4个子类 |
| unit_converter.py | `convert_and_validate(input_str, unit)` | 输入校验，英寸‑厘米换算；非法输入抛出ValueError |
| area_calculator.py | `calc_area(shape_obj)` | 接收图形对象，返回原始浮点面积，不做四舍五入 |
| result_formatter.py | `format_result(shape_obj, original_unit, area_value)` | 组装中文输出，统一保留3位小数 |

参数字典规范：
| 图形类型 | 参数字典格式 |
|---|---|
| 正方形 | `{"side": float}` |
| 长方形 | `{"length": float, "width": float}` |
| 三角形 | `{"base": float, "height": float}` |
| 圆形 | `{"diameter": float}` |
