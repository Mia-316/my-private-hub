# 第一次作业：通用面积计算器（五人分工）

> 选题：题目 2——编写一个通用面积计算器，支持计算正方形、长方形、三角形和圆形的面积。
>
> 说明：每位成员均须在自己的功能完成过程中提交代码，保留可追溯的 Git 提交记录。

## 分工

### 王澔博（组长）：图形界面

实现程序的图形界面，包括图形选择、长度单位选择、参数输入区、计算按钮和结果显示区，确保用户能够完成整个计算流程。

### 王菲：图形类设计

使用继承设计图形类：建立图形基类，以及正方形、长方形、三角形和圆形子类；实现图形类型选择功能。

### 喻麒麟：面积计算

实现四种图形的面积计算：正方形按边长计算，长方形按长和宽计算，三角形按底和高计算，圆形按直径计算。

### 荣伊润：长度输入与单位换算

实现各图形所需长度的输入功能，并支持用户选择厘米或英寸输入；将英寸统一换算为厘米。

### 杨婷：结果输出

实现计算结果输出：显示所选图形类型、输入长度和最终面积；长度使用厘米、面积使用平方厘米，均保留 3 位小数。

## 封装与文件组织建议

建议每位成员只维护一个独立的 Python 文件，避免多人同时修改同一文件。组长的界面程序只负责收集输入、调用下列公开函数并展示结果，不应重复实现各模块的计算逻辑。

```text
项目目录/
├── main.py                 # 王澔博：图形界面与各模块调用
├── shapes.py               # 王菲：图形类及继承关系
├── area_calculator.py      # 喻麒麟：面积计算公式
├── unit_converter.py       # 荣伊润：输入校验与单位换算
├── result_formatter.py     # 杨婷：结果文本格式化
└── tests/                  # 可选：各成员的自测文件
```

模块之间只调用公开函数，建议统一使用以下数据约定：

- 图形名称：`"square"`、`"rectangle"`、`"triangle"`、`"circle"`。
- 长度数据：使用字典保存，例如 `{"side": 5.0}`、`{"length": 5.0, "width": 3.0}`。进入 `shapes.py` 前，所有长度必须已换算为厘米。
- 面积数据：使用 `float`，单位为平方厘米。仅在最终输出时保留 3 位小数，计算过程中不要提前四舍五入。
- 各模块遇到无效输入时抛出 `ValueError` 并写明原因，界面层统一捕获后提示用户。

## 组员详细编写指导

### 王菲：`shapes.py`（图形类设计）

目标是体现“类的继承”。本文件只描述图形及其所需参数，不编写界面，也不处理厘米/英寸换算。

建议创建一个抽象基类 `Shape`，并派生 `Square`、`Rectangle`、`Triangle`、`Circle` 四个子类。每个子类提供自己的图形名称和所需参数名称；再提供一个工厂函数，供组长根据用户选择创建对应对象。

建议公开以下接口：

```python
class Shape:
    shape_type: str

    def __init__(self, dimensions: dict[str, float]):
        self.dimensions = dimensions

    def required_fields(self) -> tuple[str, ...]:
        raise NotImplementedError


class Square(Shape):
    shape_type = "square"

    def required_fields(self) -> tuple[str, ...]:
        return ("side",)


def create_shape(shape_type: str, dimensions: dict[str, float]) -> Shape:
    """根据图形名称返回对应子类对象；名称错误时抛出 ValueError。"""
```

四个子类所需字段应分别为：正方形 `side`、长方形 `length` 和 `width`、三角形 `base` 和 `height`、圆形 `diameter`。自测时应确认 `create_shape` 能返回正确的子类，且每个子类返回正确的字段名。

### 喻麒麟：`area_calculator.py`（面积计算）

本文件只负责面积公式。输入的所有长度默认均为厘米，返回值为平方厘米；不处理输入框文本、单位换算或小数显示。

建议为每种图形分别编写一个小函数，再用一个统一函数供其他文件调用：

```python
import math

def square_area(side: float) -> float:
    return side ** 2

def rectangle_area(length: float, width: float) -> float:
    return length * width

def triangle_area(base: float, height: float) -> float:
    return base * height / 2

def circle_area(diameter: float) -> float:
    return math.pi * (diameter / 2) ** 2

def calculate_area(shape_type: str, dimensions: dict[str, float]) -> float:
    """按图形名称分派到正确的面积公式；名称错误时抛出 ValueError。"""
```

自测数据可使用：边长 `2` 的正方形结果为 `4`；长 `3`、宽 `4` 的长方形结果为 `12`；底 `6`、高 `4` 的三角形结果为 `12`；直径 `2` 的圆面积约为 `3.141593`。不要在本文件使用 `round()`，保留完整精度给结果输出模块。

### 荣伊润：`unit_converter.py`（长度输入与单位换算）

本文件负责将界面传入的文本转换为可计算的数据。需要检查输入不能为空、必须是数字、长度必须大于零；用户选择英寸时，按 `1 英寸 = 2.54 厘米` 换算。

建议公开以下接口：

```python
INCH_TO_CM = 2.54

def parse_positive_number(text: str, field_name: str) -> float:
    """将文本转为大于 0 的浮点数；失败时抛出带字段名的 ValueError。"""

def to_centimeters(value: float, unit: str) -> float:
    """unit 仅接受 'cm' 或 'inch'；返回厘米数。"""

def parse_dimensions(raw_values: dict[str, str], unit: str) -> dict[str, float]:
    """校验并换算一组输入，返回所有值均为厘米的字典。"""
```

自测时覆盖以下情况：`"2.5"` 厘米应得到 `2.5`，`"2"` 英寸应得到 `5.08`，空字符串、`"abc"`、`"0"` 和负数均应给出明确错误信息。

### 杨婷：`result_formatter.py`（结果输出）

本文件只负责把已经计算好的数据整理成用户可读的文本，不重新计算面积，也不进行单位换算。所有长度输出为厘米，面积输出为平方厘米，且统一保留 3 位小数。

建议公开以下接口：

```python
SHAPE_NAMES = {
    "square": "正方形",
    "rectangle": "长方形",
    "triangle": "三角形",
    "circle": "圆形",
}

def format_length(value_cm: float) -> str:
    return f"{value_cm:.3f} 厘米"

def format_area(value_cm2: float) -> str:
    return f"{value_cm2:.3f} 平方厘米"

def build_result(shape_type: str, dimensions_cm: dict[str, float], area_cm2: float) -> str:
    """返回包含图形类型、各输入长度和最终面积的多行文本。"""
```

输出应至少包含图形类型、该图形实际输入的每一项长度和最终面积。例如正方形可显示“图形类型：正方形”“边长：5.000 厘米”“面积：25.000 平方厘米”。自测时确认所有数字都有且只有 3 位小数。
